# Inicio Rápido - Jaime System Cleaner

## 🚀 Comenzar en 3 pasos

### 1. Construir el paquete

```bash
cd "/home/seba/Escritorio/proyecto Jaime"
./build.sh
```

### 2. Instalar

```bash
sudo dpkg -i jaime-cleaner_1.0.0_all.deb
sudo apt-get install -f
```

### 3. Ejecutar

```bash
jaime
```

¡Listo! La aplicación se abrirá y podrás comenzar a limpiar y optimizar tu sistema.

---

## 📋 Guía de Uso Rápido

### Health Check
1. Haz clic en "Health Check" en la barra inferior
2. Selecciona los análisis que deseas realizar
3. Haz clic en "Iniciar Análisis"
4. Revisa los resultados

### Limpieza Personalizada
1. Haz clic en "Custom Clean"
2. Marca los elementos que deseas limpiar
3. Haz clic en "Iniciar Limpieza"
4. Confirma y espera a que termine

### Actualizar Sistema
1. Haz clic en "System Update"
2. Haz clic en "Buscar Actualizaciones"
3. Revisa las actualizaciones disponibles
4. Haz clic en "Instalar Actualizaciones"

### Herramientas Rápidas
1. Haz clic en "Tools"
2. Selecciona la herramienta que necesitas:
   - Reparar Gestor de Archivos
   - Limpiar Swap
   - Reparar Paquetes
   - Optimizar APT

---

## 💡 Consejos

- **Primer uso**: Realiza un Health Check para conocer el estado de tu sistema
- **Limpieza regular**: Ejecuta la limpieza personalizada semanalmente
- **Antes de limpiar**: Cierra aplicaciones importantes para evitar problemas
- **Actualizaciones**: Mantén tu sistema actualizado para mejor seguridad

---

## ⚠️ Importante

- Algunas operaciones requieren contraseña de administrador
- La limpieza elimina archivos permanentemente
- Se recomienda hacer respaldo de datos importantes
